# Claude에게 이렇게 요청합니다

```text
Claude에게 이렇게 요청합니다 (영상 속 고양이를 우리 집 고양이로)
대괄호 [ ] 부분만 바꿔서 쓰세요. 저는 Claude Code에 ComfyUI(MiniMax H3 + 스왑 LoRA)를 연결해서 만들었습니다.
모델 다운로드와 새 노드 설치는 Claude가 물어보면 직접 승인하거나, 알려 주는 명령을 직접 실행합니다.

[준비]
- 내 컴퓨터(그래픽카드 [RTX 4060 8GB])의 ComfyUI에서 MiniMax H3와 스왑 LoRA로 영상 속 고양이를 우리 고양이로 바꾸고 싶어. 필요한 모델이 다 있는지 확인하고, 없는 건 알려 줘.

[Step 1 · 참조 사진]
- 우리 고양이 사진은 [폴더]에 있어. 이 사진들로 참조 시트를 만들어 줘. 실제 사진만 쓰고, 얼굴 정면·옆얼굴·전신이 다 보이게.
  내가 하는 일: 사진 모으기 / 시트에 다른 고양이 얼굴이 섞이지 않았는지 보기

[Step 2 · 입력 영상]
- 이 영상에서 [뒤에서 춤추는 크림색 고양이]를 우리 고양이로 바꾸고 싶어. 그대로 써도 되는 영상인지 먼저 봐 줘.
- 사람이 연기한 영상이면: 사람 몸을 털색으로 칠한 입력 영상을 만들어 줘.
  내가 하는 일: 바꿀 영상 고르기 / 어느 고양이를 바꿀지 정확히 말하기

[Step 3 · 프롬프트]
- 참조 시트를 보고 얼굴, 눈, 털색, 귀를 부위별로 적은 프롬프트를 써 줘. 원본 동작과 입 모양은 그대로 따라가게.
- 결과를 보고: 눈이 우리 고양이보다 크고 밝아. 주둥이에 주황 무늬가 있는데 실제는 하얘.
  내가 하는 일: 결과와 우리 고양이의 다른 점을 구체적으로 말하기

[Step 4 · 생성]
- 먼저 1초만 시험으로 만들어서 원본과 나란히 비교 영상으로 보여 줘. 시드는 고정하고, 한 번에 하나만 바꿔.
- 괜찮으면 전체를 만들어 줘. 폰에서 진행 상황을 볼 수 있게 현황판도 만들어 줘.
  내가 하는 일: 비교 영상을 보고 다음에 무엇을 바꿀지 정하기

[Step 5 · 고급 · 여러 마리 중 하나만]
- 앞 고양이는 그대로 두고 뒤 크림색 고양이만 바꿔 줘.
- 매번 손으로 고치면 다른 사람은 못 써. 다른 사람도 똑같이 쓸 수 있게 근본적인 해결 방법을 찾아 줘.
  내가 하는 일: 새 노드 설치 명령은 직접 실행·승인 / 결과를 보고 경계·잔상 짚어 주기

[Step 6 · 선택 · 화질 올리기]
- SeedVR2로 1080p 업스케일 해 줘. 2초만 먼저 해서 단순 확대와 나란히 비교해 줘.
- 흐물흐물한 게 보이는데, 줄일 수 있을까?
  내가 하는 일: 다운로드 승인 / 보통 크기로 보고 차이가 있는지 판단

[안 될 때]
- 결과에 [사람 손이 남아 있어]. 원인 후보를 세우고, 짧은 시험으로 하나씩 확인해 줘.
- 문장으로 세 번 고쳐도 안 되면: 프롬프트 말고 참조 사진이나 입력 영상을 고치는 방법을 찾아 줘.
```
